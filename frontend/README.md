Guess-the-World 🌍

A Geoguesser-style game where players are shown a random location and must guess where in the world it is by placing a pin on a map. Points are awarded based on how close the guess is to the actual location.

Tech Stack

Frontend

Vue 3 — UI framework
Vite — build tool & dev server

Backend

Python — server-side logic
REST API for serving locations, verifying guesses, and calculating scores
